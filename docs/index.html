Jump

一个专门用来整蛊朋友的网站重定向页面

立即体验

这是什么

Jump 是一个玩笑性质的跳转页。当有人点开你分享的链接，页面不会多说一句话，而是直接把人随机带去一个整蛊内容——比如经典 Rickroll、彩虹猫、满屏弹跳猫。对方满怀期待点进来，然后一脸问号地被“整”了。

特点

随机跳转

每次打开都会从链接池中随机挑一个目标，重复被整也不会腻。

猝不及防

页面伪装成“正在跳转”的加载页，短暂停顿后才出发，毫无防备。

无法返回

跳转使用 replace 方式，对方按返回键也回不到这个页面。

怎么玩

  1. 把本网站的链接发给朋友，或者丢进群聊。
  2. 配上一句让人无法拒绝的诱饵文案，比如“快看这个，笑死我了”。
  3. 坐等对方发来一句“？？？”。

链接一览

所有整蛊链接都放在 links.txt 里，这里可以查看每条链接的内容、按关键词搜索，也可以直接复制带参数的链接，精准整蛊某一个人。
